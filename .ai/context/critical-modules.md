# Critical modules

Files where a small edit has large, delayed consequences. A defect here does not break
this repo — it ships into every service scaffolded afterwards.

## `backend-standards/references/02-security-and-compliance.md`

**The security floor for every backend service.** Highest-stakes file in the repo.

- It is a floor: a project document **MAY** tighten it, **MUST NOT** relax it. Weakening
  a MUST here weakens it fleet-wide, retroactively, for every project that re-syncs.
- It records the Class B/C logging posture — OTPs, access and refresh tokens, national
  IDs and card tokens logged **in full** — and the four conditions that decision rests
  on (`02` §1). **A change that breaks any of the four is a change to an owner-level
  decision.** Stop and raise it.
- It is **internal**. `README.md` § "Before sharing externally" is not boilerplate.
- Guarded by `.github/CODEOWNERS`.

## `backend-standards/templates/src/common/money.util.ts`

Exact arithmetic in integer minor units, zero dependencies (`ADR-004`).

- Every operation normalizes to the currency scale. **Accumulation is the risk**, not a
  single operation — the whole design exists so drift cannot compound.
- `parseAmount` is exact **only for strings**, because it moves the decimal point
  textually and never multiplies. Postgres returns `numeric` as a string, which is why
  `01` §6 requires the entity property to be typed `string`.
- Rounding is **half away from zero**, applied through one helper so a refund rounds the
  same distance as the charge it reverses. `Math.round` alone rounds half toward +∞ and
  breaks that symmetry on negatives.
- `money.util.spec.ts` is what makes the exactness claim checkable. **Ship them
  together.** Never change one without the other.

## `backend-standards/templates/src/common/sortable.ts`

The only barrier between a client's `sortBy` and an `ORDER BY` clause.

- A SQL identifier cannot be parameterized, so `sortBy` is string interpolation into SQL
  by construction. The allowlist is the control; DTO validation is defence in depth.
- Membership is checked with `Object.hasOwn`, **not** `map[key]` truthiness. A plain
  object literal inherits from `Object.prototype`, so `?sortBy=toString` returns an
  inherited function — truthy — and walks straight past a `if (!column)` guard. This was
  a real defect, fixed in 2.0.0, and `sortable.spec.ts` pins it.

## `backend-standards/templates/src/common/webhook-signature.util.ts`

- Verify **first** — before any read, lock, status check or write. A request that fails
  verification must change nothing, including an audit row.
- Comparison is constant-time. A plain `!==` on a hash leaks timing.
- Replay protection is a **separate** obligation. A valid signature does not make a
  request fresh.

## `backend-standards/templates/src/common/redis-lock.service.ts`

- Release is a Lua compare-and-delete. A bare `DEL` deletes whoever holds the lock now,
  which after your TTL expired is someone else.
- It **fails closed**: if Redis is unreachable the operation is rejected, not run
  unguarded. Skipping the lock removes mutual exclusion exactly when the system is
  degraded, which is when duplicates actually happen.
- `Redis` is a **value** import. A type-only import erases the DI metadata and the
  container cannot construct the service at all.

## `toolchain-config/templates/scripts/security-scan.mjs`

Its **exit codes** decide whether `04` Part A gates A4 and A5 can block a merge.

- Strict by default: findings exit non-zero. A scan that always exits 0 is not a gate.
- A scan that could not run has **not** passed — the Docker guard exits 127, and checks
  the daemon rather than just the CLI.
- Mounts only `src/`, `package-lock.json` and `.git/`. **Never** `env/`, `cert/` or
  `*.pem` — `02` §8 forbids tooling from reading those, and a scanner is tooling.

## `toolchain-config/templates/eslint.config.mjs` and `tsconfig.json`

- `consistent-type-imports` is **off** and must stay off while `emitDecoratorMetadata`
  is on. The rule's `--fix` rewrites injected imports and breaks DI silently, and
  lint-staged runs `--fix` on every commit.
- `esModuleInterop` must stay **with** `allowSyntheticDefaultImports`. Without it a
  default import of a CommonJS package type-checks, builds, and throws at boot.
- `useDefineForClassFields: false` must stay pinned while `target` is ES2022+, or
  decorated TypeORM fields overwrite hydrated values with `undefined`.
- The `no-restricted-syntax` rules back MUSTs in `01` §5 and §7. They are `error`, not
  part of the ratchet. Scope them per-folder in a legacy repo; do not delete them.
